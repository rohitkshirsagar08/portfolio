# Rohit Kshirsagar — Software & AI Engineering Portfolio

A modern, responsive, and accessible personal portfolio tailored for the **Software & AI Engineering (S&AI)** curriculum evaluation.

## 🎨 Theme & Visual Design
- **Soothing Color Palette**: Warm cream white (`#fdfbf7`, `#f7f2eb`), crisp white cards (`#ffffff`), and gentle sunset terracotta orange (`#ea6a32`, `#d6521e`) accents that are easy on the eyes.
- **Modern Typography**: Powered by *Plus Jakarta Sans* and *JetBrains Mono*.

## 📋 Evaluated Sections (10/10 Marks Rubric)
1. **About Me (1 Mark)**: Academic background (1st Year Sem 1 B.Tech CSE), technical areas of focus (Python runtime internals, test-driven engineering, LLM systems), and professional objectives.
2. **Skills (1.5 Marks)**: Categorized technical skills (Languages, Testing & QA, Libraries/Algorithms) where **every single skill links directly** to applied code or pull requests.
3. **S&AI Open-Source Contributions (3 Marks)**: Complete breakdown of the 10 separate pull requests on the `S-AI-Projects/learn-python` repository with Task IDs, code modification descriptions, technical rationales, and direct GitHub PR hyperlinks.
4. **Projects (2.5 Marks)**: Two technical projects (NexusGroq and Perplexity Explorer) detailing Problem Statement, Solution Architecture, Tech Stack, Individual Contribution, and repository links.
5. **Education and Achievements (1 Mark)**: Academic degree, expected graduation date (2026), and verified accomplishments with external links.
6. **Contact (1 Mark)**: Functional contact mechanisms for Email, GitHub (`@rohitkshirsagar08`), and LinkedIn.

## 🚀 Running Locally
Open `index.html` directly in any web browser or serve with Python:
```bash
python3 -m http.server 8080
```
Navigate to `http://localhost:8080`.
