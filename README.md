# Call of Duty Combat & Gameplay Programmer Portfolio
### Candidate: Rohit Kshirsagar // Target: Activision Call of Duty Studios

Tactical HUD portfolio designed for a Gameplay & Combat Programmer targeting Call of Duty (Infinity Ward, Treyarch, Sledgehammer Games).

## 🎯 Features
- **Tactical Operator Dossier**: High-tech HUD presentation showcasing combat engineering credentials.
- **Interactive Ballistics & Recoil Proving Grounds**: Real-time 2nd-order damped harmonic spring simulation (`d2x/dt2 = -k*x - c*v`) running on HTML5 Canvas.
- **Gunsmith Class Loadout (Tech Stack)**: C++20, 128-tick rollback replication, procedural recoil kinetics, and deep profiling.
- **Classified Black Ops Projects**: High-detail architecture breakdowns for deterministic ballistics engines and low-latency multiplayer architectures.
- **C++ Combat Code Vault**: Production-grade C++ snippets with interactive tabs and one-click clipboard copying.
- **Synthesized Web Audio API Engine**: Zero-asset procedural gunshot, HUD click, and radar telemetry sound effects.
- **Night Vision Goggles (NVG) Mode**: High-phosphor green optic toggle across the interface.

## 🚀 Running Locally
You can open `index.html` directly in any modern browser, or run a local static server:
```bash
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080`.
